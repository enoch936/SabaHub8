4.3.4 Access Control and Security

User Roles
- Freelancer
- Employer
- Admin

RBAC Matrix
Resource/Function | Freelancer | Employer | Admin
Manage Own Profile | Create/Update | View | View/Suspend
Upload Identity Docs | Execute | Denied | View/Audit
Approve Verifications | Denied | Denied | Execute
Manage Job Posts | Denied | Create/Update/Close | View/Audit
Manage Applications | View/Withdraw | Review/Shortlist/Offer | View/Audit
Manage All Users | Denied | Denied | Execute
System Settings | Denied | Denied | Execute

Security Mechanisms
- Authentication: OTP (email/SMS) + JWT (stateless access tokens).
- Authorization: role-based guards in Spring Security.
- Transport Security: HTTPS enforced in production.
- Data at Rest: AES-256 encryption for sensitive verification documents.
- Media Storage: Cloudinary stores binaries; MongoDB stores signed URLs and metadata.
- Secrets Management: env vars for JWT secret, SMTP, and Twilio credentials.

Threat Considerations
- Credential stuffing: OTP throttling and rate limits.
- Token replay: short token TTL and refresh rotation.
- File upload abuse: size/type validation and signed URL access.
