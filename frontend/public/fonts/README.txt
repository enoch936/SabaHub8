Place custom web fonts here. This project ships with Inter via Google Fonts in CSS typically, but you can also self-host. Example usage:

@font-face {
  font-family: 'Inter var';
  font-style: normal;
  font-weight: 100 900;
  font-display: swap;
  src: url('/fonts/Inter-VariableFont_slnt,wght.woff2') format('woff2');
}

Use CSS variables in themes to pair with typography system.
